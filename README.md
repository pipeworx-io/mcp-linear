# mcp-linear

Linear MCP — wraps the Linear GraphQL API (OAuth)

Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

## Tools

| Tool | Description |
|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "linear": {
      "url": "https://gateway.pipeworx.io/linear/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use linear
```
